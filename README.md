
# SOLESTREET - Shoe Store

SOLESTREET adalah aplikasi e-commerce sederhana untuk penjualan dan pengelolaan produk sepatu berbasis Flask dan MySQL.

## Fitur
- Dashboard Admin
- Mengelola produk
- Mengelola pelanggan
- Mengelola pesanan
- Katalog produk
- Keranjang belanja

## Teknologi
- Python (Flask)
- MySQL
- HTML
- CSS
